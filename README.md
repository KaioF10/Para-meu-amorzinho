# Para o meu amor 💗

Site estático (HTML, CSS e JS puros). Sem build, sem dependências.

## Suas fotos
Coloque 5 imagens na pasta `fotos/` com os nomes `foto1.jpg` ... `foto5.jpg`
(ou mude os caminhos e legendas no array `fotos` em `script.js`).

## Modo edição (só para você)
Abra o site com `?editar` no final do endereço (ex.: `index.html?editar`) para
editar legendas e testar fotos. As legendas ficam salvas só naquele navegador;
para deixar fixas, escreva-as no array `fotos` em `script.js`.

## Textos
Nossa História e Carta: edite direto no `index.html`.

## Publicar
- GitHub: suba esta pasta em um repositório.
- Vercel: "Add New Project", importe o repositório e clique em Deploy (sem configurar nada).

## Instalar como app no celular
- iPhone (Safari): Compartilhar → "Adicionar à Tela de Início".
- Android (Chrome): menu ⋮ → "Instalar app" ou "Adicionar à tela inicial".
O ícone é o coração pixelado em `icons/`.
